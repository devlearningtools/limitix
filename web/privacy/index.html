Privacy Policy

Limitix — last updated October 2026

Short version

Limitix reads the Usage/Settings page on Claude, ChatGPT, or Gemini — either one you already have open, or one it briefly opens itself in the background to keep your data current — and saves what it finds on your own device. It never sends anything to a server, because it doesn't have one. There is no account, no sign-in, and no tracking.

What Limitix reads

When the Usage or Settings page on claude.ai, chatgpt.com, or gemini.google.com is open, Limitix's content script reads the visible text on that page (your usage percentage and reset-time labels, such as "58% used" or "Resets at 3:10 PM"). It does not read your conversations, prompts, or any other content on these sites.

How Limitix keeps this up to date

Rather than requiring you to manually revisit each platform's Usage page, Limitix refreshes it for you, in a way designed to be invisible:

  • Roughly every 30 minutes, it briefly opens the Usage page for each platform in an unfocused browser window positioned off-screen — it never takes focus away from what you're doing — reads it, and closes that window a few seconds later.
  • Shortly after you send a message on one of these platforms, it does the same thing for just that platform, so the numbers don't lag too far behind what you're actually using.

Both of these only ever load a page that is already part of the platform itself (its own Usage/Settings page) using your existing, already-signed-in browser session. No separate login, token, or credential is involved, and nothing about this is sent anywhere — it's read locally and saved locally, the same as if you'd opened that page yourself.

What Limitix stores

The usage percentages and reset labels it reads are saved using chrome.storage.local — a storage area built into your browser, scoped to this extension, and stored only on your own device. This data is never transmitted anywhere. Limitix has no backend server, no database, and no analytics of any kind.

What Limitix does not do

  • It does not require an account, sign-in, or API key.
  • It does not send any data to a server — there isn't one.
  • It does not use cookies, analytics, or third-party trackers.
  • It does not read or store your chat messages or prompts.
  • It does not share data with any third party, because it never leaves your browser.

Permissions it requests, and why

  • storage — to save usage data locally, as described above.
  • alarms — to schedule the roughly-every-30-minute background refresh described above. This permission only lets Limitix run code on a timer; it grants no extra data access by itself.
  • Host access to claude.ai, chatgpt.com, and gemini.google.com — so its content script can read the Usage page text on those specific sites, and so it can open/close the brief background refresh windows described above. Limitix does not run on, or request access to, any other website.

Third-party platforms

Limitix is an independent, unofficial tool. It is not affiliated with, endorsed by, or sponsored by Anthropic, OpenAI, or Google. It reads only information these platforms already display to you in your own account.
