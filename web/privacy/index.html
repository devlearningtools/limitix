Privacy Policy

Limitix — last updated October 2026

Short version

Limitix reads the Usage/Settings page you already have open on Claude, ChatGPT, or Gemini, and saves what it finds on your own device. It never sends anything to a server, because it doesn't have one. There is no account, no sign-in, and no tracking.

What Limitix reads

When you open the Usage or Settings page on claude.ai, chatgpt.com, or gemini.google.com, Limitix's content script reads the visible text on that page (your usage percentage and reset-time labels, such as "58% used" or "Resets at 3:10 PM"). It does not read your conversations, prompts, or any other content on these sites.

What Limitix stores

The usage percentages and reset labels it reads are saved using chrome.storage.local — a storage area built into your browser, scoped to this extension, and stored only on your own device. This data is never transmitted anywhere. Limitix has no backend server, no database, and no analytics of any kind.

What Limitix does not do

  • It does not require an account, sign-in, or API key.
  • It does not send any data to a server — there isn't one.
  • It does not use cookies, analytics, or third-party trackers.
  • It does not read or store your chat messages or prompts.
  • It does not share data with any third party, because it never leaves your browser.

Permissions it requests, and why

  • storage — to save usage data locally, as described above.
  • Host access to claude.ai, chatgpt.com, and gemini.google.com — so its content script can read the Usage page text on those specific sites. Limitix does not run on, or request access to, any other website.

Third-party platforms

Limitix is an independent, unofficial tool. It is not affiliated with, endorsed by, or sponsored by Anthropic, OpenAI, or Google. It reads only information these platforms already display to you in your own account.
